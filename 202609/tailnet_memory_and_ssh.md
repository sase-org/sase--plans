# Tailnet Memory Note + Cross-Device Tailscale SSH Config

## Objective

Create a new chezmoi-managed SASE memory note `~/sase/memory/tailnet.md` describing
Bryan's three tailnet machines (athena, apollo, mac), and make every one of those
machines configure SSH access to the others in its `~/.ssh/config` via chezmoi.

## Background And Verified Facts

- The Tailscale tailnet is `tail297af1.ts.net`. `tailscale status` on athena shows:
  - `athena` — 100.87.31.114, Linux, Bryan's home server, SSH user `bryan`.
  - `apollo` — 100.76.155.98, Linux, DigitalOcean rendezvous server, SSH user `bryan`
    (also reachable at public IP `159.223.165.54`).
  - `kellys-macbook-pro` — 100.108.201.99, macOS, Kelly's MacBook Pro, SSH user
    `bbugyi`, chezmoi hostname `Kellys-MBP`. Offline unless powered on with the lid
    open.
- The chezmoi repo (linked repo `chezmoi`, remote `bbugyi200/dotfiles`) uses
  `.chezmoiroot = home`. `home/sase/` deploys to `~/sase/`, so `~/sase/memory/` on all
  three hosts is chezmoi-managed; `home/sase/memory/obsidian.md` is the model for a
  `type: reference` note.
- The five provider shim templates `home/AGENTS.md.tmpl`, `home/CLAUDE.md.tmpl`,
  `home/GEMINI.md.tmpl`, `home/OPENCODE.md.tmpl`, and `home/QWEN.md.tmpl` each inline
  the home project's memory (only their first header line varies by hostname). Their
  `## 2. Reference Memory` numbered list currently has one entry (`obsidian.md`) and
  must gain the new note's entry. `~/sase/memory/README.md` is generated by
  `sase memory init` and is also chezmoi-managed.
- `~/.ssh/config` is NOT chezmoi-managed on any host. Athena's copy already has ad-hoc
  blocks: `Host apollo` pointing at the DigitalOcean public IP and `Host mac` pointing
  at `kellys-macbook-pro.tail297af1.ts.net` with `IdentityFile ~/.ssh/id_rsa` +
  `IdentitiesOnly yes`.
- `home/.chezmoiignore` already guards per-host files with
  `{{ if ne .chezmoi.hostname ... }}` blocks for hostnames `athena`, `apollo`, and
  `Kellys-MBP`, plus a work host (`bbugyi.c.googlers.com`) that is NOT on the tailnet.
- Existing `home/.chezmoiscripts/run_onchange_*` scripts use `#!/bin/bash` and embed
  `{{ include "<source file>" | sha256sum }}` comments to re-trigger when a source file
  changes.
- Athena's live chezmoi source (`~/.local/share/chezmoi`) and the linked-repo checkout
  are clones of the same remote, so `chezmoi diff/apply --source <linked checkout>` can
  be used for in-turn verification on athena; apollo and mac converge on their next
  `chezmoi update` after the commit lands.

## Design Decisions

- **Shared conf + Include, not full adoption of `~/.ssh/config`:** each host's
  `~/.ssh/config` contains machine-specific and work content that should stay unmanaged.
  Instead, deploy one chezmoi-managed `~/.ssh/tailnet.conf` with host blocks for ALL
  tailnet machines, and use an idempotent `run_onchange` script to ensure
  `Include tailnet.conf` sits at the top of each host's `~/.ssh/config` (ssh resolves
  relative `Include` paths against `~/.ssh`, and top placement means these blocks win
  under ssh's first-value-wins option resolution).
- **All three host blocks on every machine:** a self-referencing block is harmless and
  keeps the conf host-independent (no templating needed).
- **Keep the mac's key pinning:** carry over `IdentityFile ~/.ssh/id_rsa` +
  `IdentitiesOnly yes` from athena's previously working `Host mac` block; ssh silently
  ignores a missing identity file, so this is safe on hosts without that key.
- **Public-IP fallback:** preserve apollo's DigitalOcean public IP as a new `apollo-do`
  alias in the shared conf so every machine keeps a route to apollo when Tailscale is
  down.
- **Non-tailnet hosts opt out:** guard both the deployed conf (via `.chezmoiignore`) and
  the script body (via a hostname template conditional) so the work host is untouched.
- **Memory note is `type: reference`:** the always-loaded description line is enough for
  discovery; the body is read on demand.

## Constraints For The Implementer

- This plan changes SASE memory files. Invoke `/sase_memory_write` before editing them;
  this approved plan is the authorization. Never hand-edit generated outputs
  (`~/AGENTS.md`, `~/CLAUDE.md`, `~/sase/memory/README.md`, ...) except by running
  `sase memory init` and syncing chezmoi sources to its output.
- Open the chezmoi repo ONLY with your `/sase_repo` skill
  (`sase repo open chezmoi -r "..."`); below, `$CHEZMOI` means the path that command
  prints. Make all source edits inside `$CHEZMOI`.
- Do not run `git commit` anywhere. The modified chezmoi repo becomes a repository
  obligation settled through `/sase_final` (host-owned completion).
- Do not propagate anything to apollo or the mac by hand (no ssh-ing over to edit
  files): they converge via `chezmoi update` once the commit lands. The mac may be
  offline; that must not block this work.

## Steps

1. **Create the memory note** at `$CHEZMOI/home/sase/memory/tailnet.md` (canonical
   source for `~/sase/memory/tailnet.md`):

   ```markdown
   ---
   type: reference
   parent: AGENTS.md
   description:
     Tailnet machines (athena, apollo, mac) - Tailscale SSH access, users, and the
     chezmoi-managed ~/.ssh/config convention.
   ---

   # Tailnet Machines

   All of Bryan's personal machines join the Tailscale tailnet `tail297af1.ts.net` and
   are reachable from each other over SSH via that tailnet.

   | SSH alias | Tailscale name       | OS    | SSH user | Machine                        |
   | --------- | -------------------- | ----- | -------- | ------------------------------ |
   | `athena`  | `athena`             | Linux | `bryan`  | Bryan's home server            |
   | `apollo`  | `apollo`             | Linux | `bryan`  | DigitalOcean rendezvous server |
   | `mac`     | `kellys-macbook-pro` | macOS | `bbugyi` | Kelly's MacBook Pro            |

   - The MacBook (`mac`) is offline unless it is powered on with its lid open. Treat SSH
     to it as best-effort and expect connection timeouts otherwise.
   - `apollo` is also reachable at its DigitalOcean public IP through the `apollo-do`
     alias, which keeps working when Tailscale is down.

   ## SSH Config Convention

   Every tailnet machine configures SSH access to the other tailnet machines through
   chezmoi:

   - The host blocks above live in the chezmoi-managed `~/.ssh/tailnet.conf`.
   - A chezmoi `run_onchange` script ensures `Include tailnet.conf` is present at the
     top of `~/.ssh/config` on each tailnet machine, creating that file if missing.
   - Add or change tailnet host blocks only in the chezmoi source
     (`private_dot_ssh/private_tailnet.conf`), never directly in a machine's
     `~/.ssh/config`; each machine picks up changes on its next `chezmoi update` or
     `chezmoi apply`.
   ```

2. **Create the shared SSH conf** at
   `$CHEZMOI/home/private_dot_ssh/private_tailnet.conf` (deploys to
   `~/.ssh/tailnet.conf`, mode 0600, with `~/.ssh` kept 0700 by the `private_` dir
   attribute):

   ```
   # Tailscale tailnet host blocks (managed by chezmoi - do not edit in place).
   # See ~/sase/memory/tailnet.md.

   Host athena
     HostName athena.tail297af1.ts.net
     User bryan

   Host apollo
     HostName apollo.tail297af1.ts.net
     User bryan

   Host apollo-do
     HostName 159.223.165.54
     User bryan

   Host mac
     HostName kellys-macbook-pro.tail297af1.ts.net
     User bbugyi
     IdentityFile ~/.ssh/id_rsa
     IdentitiesOnly yes
   ```

3. **Create the Include-ensuring script** at
   `$CHEZMOI/home/.chezmoiscripts/run_onchange_after_ensure_ssh_tailnet_include.tmpl`
   (bash, matching existing script conventions; body guarded to tailnet hosts; the
   sha256sum comment re-triggers it whenever the shared conf changes):

   ```
   {{ if or (eq .chezmoi.hostname "athena") (eq .chezmoi.hostname "apollo") (eq .chezmoi.hostname "Kellys-MBP") -}}
   #!/bin/bash

   # tailnet.conf: {{ include "private_dot_ssh/private_tailnet.conf" | sha256sum }}
   #
   # Ensure ~/.ssh/config Include's the chezmoi-managed tailnet host blocks.
   set -euo pipefail

   config="${HOME}/.ssh/config"
   mkdir -p "${HOME}/.ssh"
   chmod 700 "${HOME}/.ssh"
   if [[ ! -f "${config}" ]]; then
     printf 'Include tailnet.conf\n' >"${config}"
     chmod 600 "${config}"
     echo "Created ${config} with tailnet Include."
   elif ! grep -qE '^[[:space:]]*Include[[:space:]]+tailnet\.conf([[:space:]]|$)' "${config}"; then
     tmp="$(mktemp)"
     printf 'Include tailnet.conf\n\n' >"${tmp}"
     cat "${config}" >>"${tmp}"
     cat "${tmp}" >"${config}"
     rm -f "${tmp}"
     echo "Prepended tailnet Include to ${config}."
   else
     echo "Tailnet Include already present in ${config}."
   fi
   {{ end -}}
   ```

4. **Exclude non-tailnet hosts** by appending to `$CHEZMOI/home/.chezmoiignore`,
   matching its existing style:

   ```
   {{ if and (ne .chezmoi.hostname "athena") (ne .chezmoi.hostname "apollo") (ne .chezmoi.hostname "Kellys-MBP") }}
   .ssh/tailnet.conf
   {{ end }}
   ```

5. **Add the reference-memory entry to all five shim templates**
   (`$CHEZMOI/home/{AGENTS,CLAUDE,GEMINI,OPENCODE,QWEN}.md.tmpl`): in the
   `## 2. Reference Memory` numbered list, after the `obsidian.md` entry, add a `2.`
   entry for `sase/memory/tailnet.md` with the note's description. Treat the exact
   wording produced by `sase memory init` in step 6 as authoritative and reconcile the
   templates to it.

6. **Apply on athena and regenerate.** From athena (targeted apply only — do not apply
   unrelated drift):

   ```bash
   chezmoi diff --source "$CHEZMOI"   # review: only the intended paths should appear
   chezmoi apply --source "$CHEZMOI" ~/.ssh ~/sase/memory ~/AGENTS.md ~/CLAUDE.md ~/GEMINI.md ~/OPENCODE.md ~/QWEN.md
   (cd ~ && sase memory init)
   ```

   Then reconcile: copy any differences `sase memory init` produced in `~/AGENTS.md`,
   the provider shims, and `~/sase/memory/README.md` back into the corresponding
   `$CHEZMOI` sources (shim edits go into the `.tmpl` files, preserving their
   hostname-conditional first line; the README source is plain
   `home/sase/memory/README.md`). Repeat `chezmoi diff --source "$CHEZMOI"` and targeted
   apply until it reports no pending changes for those paths.

7. **Clean up athena's local `~/.ssh/config`** (direct edit; this file stays unmanaged):
   remove the now-superseded `# DIGITAL OCEAN` `Host apollo` block and the `# TAILSCALE`
   `Host mac` block (both are covered by `~/.ssh/tailnet.conf`; the public IP lives on
   as `apollo-do`). Keep `Host artemis` and everything else. Confirm the run_onchange
   script placed `Include tailnet.conf` at the top of the file.

## Verification

Run on athena; all must pass except where marked best-effort:

- `test -f ~/.ssh/tailnet.conf` and `grep -m1 '^Include tailnet.conf' ~/.ssh/config`.
- `ssh -G athena`, `ssh -G apollo`, `ssh -G mac` each report the expected `hostname`
  (`<name>.tail297af1.ts.net`) and `user` (`bryan`/`bryan`/`bbugyi`); `ssh -G apollo-do`
  reports `hostname 159.223.165.54`.
- `ssh -o ConnectTimeout=5 apollo true` exits 0.
- Best-effort: `ssh -o ConnectTimeout=5 mac true` exits 0 if `tailscale status` shows
  `kellys-macbook-pro` online; if it is offline, note that and move on.
- `chezmoi diff --source "$CHEZMOI"` shows no pending changes for `~/.ssh`,
  `~/sase/memory`, or the five shim targets.
- `(cd ~ && sase memory read tailnet.md --reason "verify new tailnet note")` prints the
  note, and `~/CLAUDE.md`'s Reference Memory list shows the new entry.
- `git -C "$CHEZMOI" status --porcelain` lists only the files this plan touches.

the shim updates automatically on their next `chezmoi update`/`chezmoi apply` after the
chezmoi commit lands. Do not ssh to them to force this.
